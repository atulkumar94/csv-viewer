CSV Viewer

Open a CSV file to view it as a table you can sort and filter. Your file is processed on your device and is never uploaded.

Working…

Tap or click a column name to sort. Type in the box under a column name to filter. Filter help

How to use it

  1. Choose a CSV file, or drag one onto the box above.
  2. Click a column name to sort: ascending, then descending, then back to the original order. Shift+click, or tick Sort by several columns, to sort by more than one column.
  3. Type in the box under a column name to filter it, or use the search box to look across all columns.
  4. Use Export view to download just the rows you filtered, in the order you sorted them.

Filters ignore upper and lower case. Columns marked # hold numbers and columns marked date hold dates; they sort by value, not alphabetically. Blank cells always sort last.

Is my data private?

Yes. Your file is read and processed entirely inside your browser, on your own device. It is never uploaded, and the page is technically blocked from sending data anywhere. See the privacy policy.

How big a file can it open?

The work happens in the background, so the page stays responsive while large files load. Files of several hundred megabytes usually open on a desktop or laptop; the real limit is your device's memory. Phones and tablets have less memory, so very large files may not open there.

Which files work?

Any text file with values separated by commas, semicolons, tabs or pipes, including .csv, .tsv and .txt exports from Excel, Google Sheets, databases and most other software. The first row is used as the column names. Files must be UTF-8 encoded, which is the default for most software today.
